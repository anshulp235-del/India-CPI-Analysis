# India CPI Inflation Analysis Dashboard
## Project Overview
An Excel-based data analytics project exploring India's Consumer Price Index (CPI) and inflation trends using monthly data from 2013 to April 2023.

## Objectives
- Analyze CPI contribution across broad categories.
- Track year-on-year (YoY) inflation trends from 2017.
- Examine food inflation and month-on-month (MoM) changes.
- Compare CPI trends before and after COVID-19.
- Analyze relationships between CPI category changes and Oils & Fats CPI.

## Tools & Techniques
- Microsoft Excel
- Data Cleaning
- Excel Formulas: XLOOKUP, SUMIFS, IFERROR
- PivotTables and Charts
- KPI Cards and Dashboard Design
- Correlation Analysis using CORREL

## Key Findings
- Highest annual average YoY inflation: 6.62% in 2022.
- Highest monthly food CPI increase: 1.01% in October 2022.
- Lowest monthly food CPI change: -1.35% in December 2022.
- Strongest positive correlation with Oils & Fats CPI changes: Fuel & Light (0.57).

## Limitations
- Category contributions in Q1 use the equal-weight assumption specified in the case study, not official CPI expenditure weights.
- Oils & Fats CPI is used as a proxy for oil-related movements because actual imported crude oil prices are not included in the dataset.
- April 2019 data is missing from the source.
